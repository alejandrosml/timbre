# HTML read by `html::to_text`, each with what WebKit (Apple Mail) does.
# "hide": SECRET is not shown, and the text is not withheld.
# "show": VISIBLE is shown.
# "withhold": SECRET is not shown; withholding the text is fine (hostile input).
# "split": VISIBLE is shown and SECRET is not.
# @@REP(n,text)@@ stands for text written n times.
# Most come from the second, third and fourth reviews of Timbre 0.5.2 (the
# third's named A1, B2…; the fourth's P1, S1, C1…). A word after a picture
# on a first line is hidden with the rest (P4e, P4g): it may be on the next
# line. WebKit's 9-pixel floor for small relative font sizes is not
# assumed: Mail may set it otherwise, and text would then be shown that
# Mail hides.
